Go State Engine

API for the Go state engine. A state engine returns a state and array of valid actions, given a state and action.

This code is adapted from minigo/go, commit 7b44376, under the Apache 2.0 license.

A board is an NxN numpy array.

A Coordinate is a tuple index into the board.

A move is a (Coordinate c | None). (coordinate or null)

A PlayerMove is a (color, move) tuple.

Go State Engine

Board state, scoring, player turn, etc. are all managed internally by the state engine through the Position and LibertyTracker classes.

Represent a baord as a numpy array. 0: empty, 1: black, -1: white. Swapping colors is as simple as multiplying an array by -1.

MISSING_GROUP_ID represents “group not found” in the LibertyTracker object.

Position.play_move

 Position.play_move (c, color=None, mutate:bool=False)

Obeys CGOS Rules of Play: No suicides, Chinese/area scoring, Positional superko (this is approximated in this implementation). The last 7 board deltas are used to extract the last 8 board states.

Type Default Details
c
color NoneType None
mutate bool False modifies in place if True

Returns a Position engine object.

If coordinate c is None, the move is a pass. If color is None, the engine’s current player is used. mutate will modify the engine object if True, otherwise it’ll return a copy.

The color parameter is only recommended for debugging.

Concatenates changes to state onto Position.board_deltas and drops everything past the 7th delta.

Board Deltas track player moves and are used to build a rolling history of state. We can subtract deltas from the current state to rebuild the game’s state up to 7 turns back.

7
